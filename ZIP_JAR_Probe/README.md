# ZIP_JAR_Probe — first passing ZIP/JAR milestone

Frozen **PPSA99867 01.000.000**, confirmed ALL PASS on PS5 firmware 13.60
by the user on 2026-10-13.

The four rows initialize the runtime, create the real interpreter-mode Java 25
VM, execute ZipJar25 and destroy the VM. The Java test validates stored and
deflated ZIP bytes, manifest parsing, URLClassLoader definition/execution of
a JAR-only class, its defining loader, arithmetic and UTF-8 resource reading.
JNI DefineClass launches the harness only; the payload class is loaded from
the JAR using Java's actual loader.

[Download the passing app ZIP, checksum and validation record](https://github.com/mateo-cogeanu/ps5-java25-homebrew/releases/tag/ZIP_JAR_Probe-v01.000.000).
Extract and install the full PPSA99867 folder in the existing homebrew scan
location. The first JVM and File I/O passing snapshots remain preserved.

## Reproduce

Run from this directory with the pinned dependencies/toolchain prepared:

```sh
python3 tools/java25_source.py --bootstrap --build-hotspot --build-base
python3 tools/package_java25_jni.py --zipjar
python3 tools/test_java25_zipjar.py
```

The Java fixture archive is generated by tools/java25_jar_fixture.py. Only
source is tracked; binaries are release assets. See validation.json for
console results and the exact package SHA-256. This folder stays frozen;
subsequent changes belong in ../Development.

Signed archives, automatic system application class-path discovery, complex
dependency graphs, mod loaders, networking, JIT stability and Minecraft are
not validated by this milestone. Preserve upstream licenses and notices.
