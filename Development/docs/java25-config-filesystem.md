# Configuration filesystem compatibility (0113)

A console crash reaches UnixNativeDispatcher.statvfs0 through NIO file copying. The target image imports statvfs without a local implementation; execution faults at a nonexecutable native address. The PS5 NIO branch and java.io File space-query branch now use the existing SDK statfs call and its real block counters, matching the established macOS conversion shape. No disk capacity is fabricated. Errors and EINTR retry behavior remain intact. This changes pathname statistics only in File and NIO; optional direct-I/O fstatvfs support is still unported.

Separately, java.io JDK_Canonicalize fails with EPERM where native realpath is denied in a title sandbox. The PS5 path now reuses the existing ps5Realpath descriptor walker on EPERM, including when resolving an existing parent of a not-yet-created configuration file. Native successful paths retain normal link resolution. The fallback verifies prefixes with non-following opens; a known ELOOP on the original path is rejected instead of being appended as an unresolved final suffix. Missing suffixes retain the existing File canonicalization contract, distinct from NIO toRealPath. Other platforms and other native errors keep their existing paths.

Host validation compiles the actual statistics JNI and JDK canonicalizer/path-collapse code with the shared descriptor helper. In a real JVM it checks all four statistics fields against real statfs results, EINTR retry, permission/missing-file errors, repeated NIO file copies and public File space queries/getCanonicalPath. Injected EPERM checks existing files, missing configuration suffixes, dot/parent components and symlink refusal; ordinary native link resolution and EIO control remain. XcheckJNI/UBSan pass. Existing descriptor/NIO/ZipFS controls and bounded descriptor ASan/UBSan tests pass. Target java.base-libs and exact patch checks pass.

Actual PS5 file statistics, configuration writes/replacement, sandbox failures, saved data and application startup remain pending. Frozen passing snapshots remain unchanged.

Console104 still terminates at the statistics JNI entry with no current fatal report. Native statfs execution/ABI is not established; patch0114 supersedes pathname capacity calls with honest unavailable results while retaining the canonicalization repair.
